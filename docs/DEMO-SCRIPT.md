# Interview Demo Script — 6 to 8 minutes

## 1. Start with the business problem (45 seconds)

"The problem I wanted to solve was not chatbot adoption. The problem was an order-to-delivery customer-service cycle that could take approximately four days because representatives had to coordinate across order management, finance, fulfillment, carriers, and invoices. The target was same-day service."

## 2. Show order recovery (2 minutes)

Use the **Recover order number** scenario.

Explain that items purchased help locate candidates but do not prove identity. Show OTP verification and the governance console changing from Restricted to Authorized.

Senior PM talking point: security, customer experience, and process redesign were designed together rather than added after development.

## 3. Show deterministic enterprise tools (2 minutes)

Run payment, pickup, delivery, and invoice scenarios.

Point to the Tool Trace. Explain that the agent decides what it needs, but transactional truth comes from deterministic services.

## 4. Show auditability (1 minute)

Point to the audit log and explain how this supports incident review, compliance, model/tool quality, and operational ownership.

## 5. Close with delivery leadership (1–2 minutes)

Explain the workstreams: process baseline, MVP backlog, integrations, identity/security, pilot, adoption, operational readiness, and KPI benefits realization.

Close with the target outcome: **~4 days → same-day resolution**.
